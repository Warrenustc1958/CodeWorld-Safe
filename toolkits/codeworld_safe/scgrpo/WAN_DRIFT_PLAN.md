- 数据：L1 配对采集，512 个 episode，从 t0=8 的关键帧出发跑 256 步（34 个不同起点），冻结 π0.5 在 Wan 观测上闭环运行。同步 LIBERO 执行同一组动作，并逐步渲染真实帧。数据在 `work/scgrpo/causal/l1{a,b}/dump`。

- P4–P6 已用全部 512 个 episode 复核（11-03 14:40），各项数字与 256 个 episode 时的差别不超过 ±0.02，结论不变。汇总在 `work/scgrpo/drift/l1/replay/summary.txt`。
- 置信区间按起始关键帧做聚类 bootstrap。

## 1. 实测结论

### 1.1 P1：同一动作、同一真实状态下的配对漂移

| 步数 | agent MAE | 静态复制 | wrist MAE | 静态复制 | EEF 误差 cm | 读出器误差下限 | Wan 误判成功 / 漏判 |
|---|---|---|---|---|---|---|---|
| 8 | 3.4 | 4.8 | 7.0 | 18.1 | 2.9 | 2.7 | .000 / .000 |
| 64 | 5.5 | 9.6 | 27.2 | 39.0 | 5.1 | 2.8 | .039 / .014 |
| 128 | 8.6 | 14.1 | 36.9 | 38.6 | 5.2 | 3.1 | .080 / .037 |
| 256 | 11.9 | 14.6 | 45.9 | 34.8 | 8.9 | 4.1 | .123 / .033 |

- 几何量本身在退化，不只是 RM 判断变差。从第 150 步左右起，wrist 的误差超过"一直重复真实起始帧"。
- RM 在第 17–32 块上的 AUROC：Wan 帧 .878，真实帧 .942（真实帧本身也从 .992 降到 .942）。Wan 带来约 .06 的额外下降，而且分歧主要是 Wan 帧上误判成功，符合 `RESEARCH_RM_WAN` 定理 7。

### 1.2 P4：在深度 d 用真实帧替换历史，之后的误差相对 free rollout 的比值

下一块误差是 teacher-forced 的单块误差：

| d | agent：下一块 / 4 块后 / 16 块后 | wrist：下一块 / 4 块后 / 16 块后 | teacher-forced 单块 MAE（agent/wrist） |
|---|---|---|---|
| 4 | .74 / .88 / 1.01 | .43 / .84 / 1.01 | 3.5 / 7.9 |
| 8 | .60 / .83 / .99 | .30 / .73 / .99 | 3.5 / 9.2 |
| 16 | .47 / .66 / .93 | .25 / .63 / .96 | 3.9 / 8.7 |
| 24 | .41 / .61 / — | .23 / .60 / — | 3.9 / 9.2 |

- **长程误差绝大部分是从历史继承来的。** 在第 16–24 块，换成真实历史后下一块误差只剩 23–47%，所以 53–77% 来自错误的历史。
- **teacher-forced 单块误差不随深度变大。** 后期状态上的单段动力学并没有变差。这和冒烟测试时浅深度下"单块误差为主"的初步判断不同，那个判断已作废。
- **一次纠偏的收益很快消失。** 半衰期约 2–4 块，8–16 块后基本没有了。纠偏必须每个 chunk 都做，一次性重锚不够。

### 1.3 P3/P5：历史敏感性和传播增益

只改历史、噪声相同，看下一块离 oracle chunk 有多远（MAE，agent/wrist）：

| 历史换成 | d=4 | d=24 |
|---|---|---|
| 只换噪声（尺度参照） | 1.3 / 2.3 | 1.6 / 3.0 |
| anchor 复制 | 12 / 39 | 16 / 44 |
| 别的起点的真实帧 | 63 / 69 | 68 / 74 |
| Wan 自己生成的历史 | 4.0 / 13 | 10.5 / 37 |

- Wan 对历史高度敏感，所以在历史上纠偏是有效的抓手。
- 传播增益 = 输出偏差 / 历史偏差：agent .93–.98，wrist .88–.92。历史误差几乎原样传下去，没有回复力。

### 1.4 视角耦合

- 只修 wrist 历史：wrist 的收益和全修几乎一样（d=16 时下一块 .25），agent 不受影响（1.02–1.04）。
- 只修 agent 历史：agent 收益和全修一样，wrist 不受影响（1.00–1.07）。
- 两个视角的误差基本是各自从自己的历史里传下来的，互相影响很小。
- EEF 读数的改善主要来自 wrist 历史。

### 1.5 P6：同一组动作下，多个新噪声 rollout 的偏差/方差拆分

方差占像素 MSE 的比例：agent .06 → .19，wrist .18 → .28，随深度从第 1 块到第 32 块逐渐上升。偏差占主导。

### 1.6 R5：动作效应（EEF 位移，用读出器估计）

| 深度（chunk） | 真实位移 cm | Wan 位移 cm | 差值中位数 cm | 方向余弦 | 幅度比 |
|---|---|---|---|---|---|
| 1–4 | 4.5 | 5.5 | 2.6 | .90 | 1.17 |
| 9–16 | 5.0 | 5.8 | 2.5 | .92 | 1.01 |
| 25–32 | 2.6 | 4.3 | 2.4 | .70 | 1.35 |

- 余弦只在机器人确实移动的 chunk 上算，即真实位移大于 1 cm。
- Wan 对动作的响应方向基本是对的，幅度略大。每块的动作效应误差约 2.4 cm，不随深度增长。
- 把这个误差当随机游走累积，32 块后约 13 cm，和实测的 EEF 漂移（约 9 cm，减去读出器下限约 5 cm）是同一量级。
- 所以腕部的问题主要不是"动作控制不了它"，而是**没有绝对位姿锚点**：每块的位移误差只累积、不回拉。
- 这里的差值包含读出器噪声，偏保守。

### 1.7 R6：动作尺度（π0.5 vs Wan 训练集）

脚本：`drift/r4_r6_pose_action.py`。训练集取 cws_v1 train 中 561 条 episode 的录制动作。

| | 位置维 std | 旋转维 std | 位置 \|a\| 99 分位 | 每步位置动作 < 0.01 的比例 | 乘 8 后触发截断 |
|---|---|---|---|---|---|
| Wan 训练集 | .10–.13 | .033–.035 | .61–.80 | .65 | 4.8% |
| L1 中的 π0.5 | .003–.005 | .003–.011 | .013–.023 | .86 | 0 |

- π0.5 的动作标准差比训练集小 10–40 倍。它几乎一直处在训练分布中"小动作"那一端。训练集里有大幅扰动（99 分位 0.6–0.8），π0.5 的动作里没有。
- 1.6 节里幅度比 1.0–1.35（Wan 的位移偏大）可能和这一点有关：小动作在 Wan 的动作嵌入里信号很弱。T1 训练时考虑按 π0.5 的动作分布重采样训练窗口，或者改动作归一化。这条还没有验证。

### 1.8 R4：EEF 位姿估计器（256 步内，相对真实状态的中位误差）

| 估计器 | 64 步 位置 cm / 旋转 ° | 128 步 | 256 步 | 256 步位置 90 分位 |
|---|---|---|---|---|
| 读出器作用在 Wan 帧上（策略现在拿到的 proprio） | 4.8 / 32.0 | 5.3 / 35.0 | 8.8 / 47.6 | 18.0 |
| 读出器作用在真实帧上（读出器自身误差下限） | 3.7 / 4.3 | 4.0 / 5.3 | 5.0 / 9.6 | — |
| 动作积分，用 step_e 拟合 | 15.8 / 4.5 | 24.5 / 7.8 | 24.1 / 14.8 | 41.1 |
| **动作积分，用 L1 拟合（按起点 2 折交叉）** | **1.6 / 1.4** | **1.9 / 2.3** | **3.0 / 3.3** | **6.8** |
| 积分与读出融合，k = .5 / .25 / .1 | 4.4–8.9 / 18–32 | 6–17 / 25–33 | 9–11 / 42–48 | 17–25 |

- **最好的估计器是动作积分，而且要用 π0.5 自己的轨迹来拟合。** 256 步时位置 3.0 cm、旋转 3.3°，比读出器在真实帧上的误差还小。把它当作纠偏参考和 T1 的推理输入。
- **用 step_e 拟合不行**（每步增量的 R² 只有 0.10–0.19）。原因大概是 step_e 里的大幅扰动经过控制器截断和接触后，动作和位移的关系不再是线性的，而 π0.5 的小动作正好落在线性区。这也意味着策略经过 GRPO 改变之后，积分器要用新的同步仿真数据重新拟合，成本很低。
- **和读出器融合反而更差。** 读出器在 Wan 帧上的误差是系统性漂移，不是独立噪声，融合等于把漂移引了进来。
- **Wan 的 wrist 帧把相机朝向画错了。** 读出器在 Wan 帧上的旋转误差从第 8 步的 5° 涨到第 256 步的 48°，而在真实帧上只有 4–10°。
- **对策略输入也有影响。** π0.5 在 Wan 里拿到的 proprio 就是这个读出值，256 步时旋转误差 48°。如果在 Wan rollout 里改为喂动作积分的 proprio，误差会降到约 3 cm / 3°。这改的是策略输入而不是 Wan 本身，可以作为一个独立的低成本改进，并入 T5 的 GRPO 对照。

更正：1.6 节"每块动作效应误差约 2.4 cm"里包含了读出器的噪声和 Wan 帧上的朝向漂移，真实的动作效应误差应该更小。

### 1.9 R7：dual-41k 对 π0.5 尺度动作的响应（teacher-forced，48 个 episode × 深度 4/8/16/24）

脚本：`drift/r7_action_sensitivity.py`。给真实历史和同一份噪声，只改这一块的 8 步动作。

| 改动 | 输出相对原动作的 MAE（agent / wrist） | 相对真实帧的 MAE（agent / wrist） |
|---|---|---|
| 原动作 | 0 / 0 | 3.79 / 8.97 |
| 只换噪声（参照） | 0.86 / 2.71 | 3.74 / 8.99 |
| 位姿置零 | 2.60 / 6.31 | 5.23 / 11.49 |
| 位姿 ×3 | 3.80 / 8.20 | 5.98 / 12.40 |
| 位姿 ×25（训练集尺度） | 7.63 / 18.24 | 9.20 / 19.41 |
| 夹爪取反 | 0.66 / 6.53 | 3.87 / 12.99 |

- **dual-41k 用到了 π0.5 尺度的位姿输入。** 位姿置零造成的变化是只换噪声的 2.3–3 倍，而且误差会变大，说明这个小幅动作信号是有用的。2 个 episode 的小测试里"置零和换噪声差不多"是因为那两条里机器人几乎没动（真实位移中位数 0.39 cm），那个结论作废。
- 输入能量的悬殊仍然存在：π0.5 每步位姿 |a| ≈ 0.0011（×8 后约 0.009），夹爪约 1.0。但 Wan 并没有因此忽略位姿。
- **给了正确动作和真实历史，单块误差仍有 3.8 / 9.0。** 位姿置零只让它升到 5.2 / 11.5，所以单块误差的大头不是动作没读进去。
- 夹爪取反只影响 wrist（agent 0.66，和换噪声差不多），符合夹爪只在 wrist 视角里可见。
- 读出器量的位移（原动作 4.5 cm，真实 1.6 cm）受读出器噪声（约 3–4 cm）支配，这个尺度下不可靠，不据此判断幅度偏差。

**决策门：**

| 门 | 结果 | 结论 |
|---|---|---|
| R1：α=.5 时 256 步 wrist MAE ≤ 25 | 14.5；α=.25 也有 24.0 | **通过**。纠偏器只要每块拉回 25–50% 的历史误差，就能过 `PLAN_next` 线 A 的门（128 步 wrist ≤ 25、第 17–32 块一致率 ≥ .90） |
| R2：每 2 块纠一次接近每块都纠 | 16.7 vs 9.8 | **不通过**。必须每块都纠；同样的平均剂量下，每块部分纠正优于隔块全换（α=.5 每块 14.5 vs 每 2 块全换 16.7） |
| R3：动作积分位姿能拿回 ≥ 50% 的 oracle wrist 收益 | (46.6 − 21.3) / (46.6 − 9.4) = 68%；真实位姿 76%，读出器 62% | **通过** |
| dual-41k 能否作 T1 起点 | 每块全换真实历史时，256 步旋转 12.4°，读出器在真实帧上的下限 9.6° | **可以**。历史对了它能把朝向画对，漂移来自累积 |

**其他发现：**
- **像素混合与 latent 混合效果接近**（α=.5：14.5 vs 15.9）。纠偏可以在 latent 上做，正好对应 T2 的插入点。
- **小误差区间符合线性递推的预测。** 每块纠偏剂量为 α 时，平衡误差 e* ≈ b / (1 − L(1 − α))。用 wrist 的 b ≈ 9、L ≈ 0.9 代入：α=.25 / .5 / .75 预测 27.7 / 16.4 / 11.6，实测 24.0 / 14.5 / 11.2。free（α=0）时 MAE 本身会饱和，agent 在 256 步内也还没到平衡点，所以那两种情况线性模型不适用。
- **只修 wrist 位姿能把朝向基本修正**（按动作积分位姿检索，旋转 14.2°，wrist 全换真实为 13.4°，free 为 48.6°），但 RM 一致率几乎不提高（.865 vs free .859）。原因是检索来的帧取自其他 episode，物体状态和 agent 视角仍是错的。所以位姿条件（T1）解决几何问题，**决策层面的收益需要两个视角都纠偏、并带上物体状态（T2）**。
- 注意：检索池是同一起点的其他 episode，初始场景一样，所以 68% 里包含了一部分场景外观的信息，不全是位姿本身的贡献。

## 2. 对 Opus 方案的取舍

| Opus 方案里的部分 | 实测依据 | 处理 |
|---|---|---|
| 在历史槽位（latent 第 1 格）纠偏 | 历史占后期误差的 53–77%；增益约 1；必须每块都做 | **保留，作为主线** |
| 因果动作记忆 | 动作方向基本对、缺绝对位姿锚；wrist 误差几乎全来自 wrist 历史 | **保留，但第一版只做 EEF 位姿加夹爪（8 维）**，物体状态以后再说 |
| L_abs / L_repair | 偏差主导 | 保留 |
| L_hist（抑制历史扰动） | 增益约 1，但目标应该是"回到真实"，不是"对历史不敏感" | 改为让历史回到真实参考，并入 L_repair |
| L_act 和动作轴分叉数据 | 方向余弦 .70–.92、幅度比 1.0–1.35，没有明显失控 | 暂缓；只在 T1/T2 之后幅度偏差还在时才加 |
| L_seed | 方差只占 6–28% | 删除 |
| 两个视角统一处理 | 两个视角的误差基本解耦 | 两个视角分别纠偏，wrist 优先 |

## 3. 降低长程误差和提高腕部可控性的思路

误差递推 e(d+1) ≈ L·e(d) + b。实测 L ≈ 0.9–1，b 是 teacher-forced 单块误差，不随深度变。所以：

1. **主要杠杆是把 L 压下去。** 每个 chunk 都把历史往真实方向拉回 κ 比例，有效增益变成 L(1 − κ)。b 已经小且稳定，优先级低。
2. **纠偏需要一个不依赖生成图像的参考。** wrist 视角由 EEF 位姿加场景外观决定。EEF 位姿可以从动作因果地积分出来，单块误差约 2.4 cm 且不增长，再配合对已生成帧的读出做融合，就能提供这个参考。这对应 Opus 方案的"因果记忆"，但要落到具体的 8 维状态上。
3. **腕部可控性 = 绝对位姿一致。** 目标是在同一动作序列下，Wan 的 wrist 帧在 256 步内和真实 EEF 位姿保持一致，而不是让 Wan 对动作更敏感。

## 4. 免训练实验（用 L1 数据和回放工具，只增加回放模式）

| 编号 | 实验 | 回答的问题 | 决策门 |
|---|---|---|---|
| R1 | 每块都纠偏，剂量 α ∈ {.25, .5, .75, 1}：历史 = α·真实 + (1−α)·生成，分 latent 和像素两种混合，跑到 256 步 | 纠偏器需要多准（κ），才能把 256 步误差压到多少 | α=.5 时 256 步 wrist MAE ≤ 25 → 学一个纠偏器有意义 |
| R2 | 每 N 块用真实帧纠偏一次，N ∈ {1, 2, 4, 8} | 纠偏频率和误差的关系 | 若 N=2 已接近 N=1，推理时可以隔块纠偏 |
| R3 | 只修 wrist 位姿：从 L1 的真实 wrist 帧池里按 EEF 位姿最近邻检索帧，替换 wrist 历史。位姿分三档：真实 EEF、动作积分 EEF、Wan 帧读出的 EEF | 只给位姿能拿回"oracle wrist"收益的多少 | 动作积分那一档能拿回 ≥ 50% → T1 值得做 |
| R4 | EEF 位姿估计器比较：动作积分（用 L1 真实数据拟合每维增益）、读出器、两者用卡尔曼式融合，看 256 步内的误差 | 推理时用哪个位姿来源 | 选 256 步误差最小的，作为 T1/T2 推理时的输入 |
| R6 | 动作尺度核对：对比训练 index 的动作分布和 L1 中 π0.5 的动作分布 | 小动作是否处在训练分布的稀疏区 | 显著偏小 → T1 一并调整 `pose_scale`，或按分位做归一化 |

R1 和 R2 只需要给 `p_replay.py` 加模式，大约半天。R3 和 R4 用 CPU 加一张卡。R6 只用 CPU。

## 5. 需要训练的实验（按顺序，每项先过门）

| 编号 | 内容 | 前提 | 判定 |
|---|---|---|---|
| T0 | 扩充数据：L1 式配对采集，约 3000 个 episode，覆盖约 500 个起点（每 512 个 episode 在 16 卡上约 50 分钟、约 10 GB） | — | 按起点划分 train/val/test |
| T1a（可选，作为 T1 的消融） | 动作重新归一化，从 dual-41k 续训：位姿各维按训练集稳健统计量归一化或加可学习逐维仿射，新层初始化成与旧 ×8 映射等价；训练窗口按 π0.5 的动作分布重采样 | R7 已显示 dual-41k 在 π0.5 尺度下确实用到了位姿输入（见 1.9），所以这不是前置条件；只在 T1 之后单块 teacher-forced 误差仍偏高时再做 | teacher-forced 单块 wrist MAE 下降；R7 位姿置零的效应变大；64 步不退化 |
| T1 | **wrist 位姿条件**（即 A3/D3）：每帧注入 8 维 EEF 和夹爪状态，零初始化后加到时间嵌入或 cross-attn token；训练时用仿真器测量值，推理时用 R4 选出的估计器（L1 拟合的动作积分）。在 T1a 的基础上做，并和 T1a 单独做消融 | R3 过门 | 256 步 wrist MAE 低于静态复制（34.8）；64 步不退化；把位姿打乱后 loss 要变差（证明条件被用上） |
| T2 | **每块历史纠偏 adapter**：只作用于 latent 第 1 格，两个视角分开，输入是生成的历史加 T1 的位姿估计，目标是真实历史的编码。训练数据用 L1/T0 的生成历史和真实历史配对，Wan 冻结或只开 LoRA | R1 过门 | 达到 R1 中 α=.5 的水平；对照 T3 |
| T3 | **仿真器 forcing 对照**（即 D1/A2）：直接用"生成历史 + 动作 → 真实下一块"微调 Wan，不加 adapter；需要给 `train_wan_cws.py` 加一个读 L1 配对数据的 dataset | 和 T2 并行 | T2 必须在相同算力下胜过 T3，否则主贡献收缩到数据和诊断 |
| T4 | L_act | T1/T2 之后 R5 的幅度比仍 > 1.2 | 幅度比回到约 1，方向余弦不下降 |
| T5 | 冻结策略的配对评估（同一 L1 框架）→ Wan_old/new × oracle/RM 的 2×2 GRPO | T1/T2 过门 | 同 Opus 方案阶段 C |

关于训练的说明：
- `train_wan_cws.py` 目前只读真实视频的 index，T3 和 T2 都需要新增一个配对 dataset。
- 本机只有 EMA 权重，续训要从 EMA 起步并重新 warmup。FA3 的反向还没验证过（`PLAN_next` S2）。
- 评测统一用 L1 框架：P1 曲线、R5、RM 一致率，以及 `wrist_sens.py` 测 Wan 的 wrist 帧对策略动作的影响。

## 6. 局限

- 只有 34 个起点，都是 t0=8 的初态，策略只有 base π0.5。扩到中段关键帧和训练后的策略之后，要重测 P1 和 P4。
- EEF 用的是 StateReader 读数，误差下限约 2.7–4 cm。物体状态还没测；若要测，可以从 `real_qpos` 和真实分割图取。
- 像素 MAE 对小物体不敏感。T1/T2 的判定要同时看 EEF、RM 一致率，以及（可行的话）物体位置。
