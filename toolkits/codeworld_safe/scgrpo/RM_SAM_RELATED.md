# RM / SAM 相关工作阅读笔记与我们的创新空间（2026-11-01）

PDF 与抽取文本在本目录：`2610.30814_DRILL`、`2610.17922_WoVR+`、`2610.32208_Do_VLAs_Know_They_Will_Fail`（.pdf / .txt）。

## 1. 三篇论文怎么做奖励 / 失败判定

### WoVR+（arXiv 2610.17922，附录 B、表 X）
- RM：每个任务（长程任务则每个阶段）一个轻量 ResNet 二分类器，输入三视角图像竖向拼接，不用动作、本体状态和历史。
- 标签：首次标注成功之后的帧为正，之前的帧和失败轨迹的所有帧为负；按类别频率反比采样。
- 使用：成功一旦被判出就锁存（latch），有效长度截到首次成功，之后的步不参与优化；RL 期间 RM 冻结。
- 应对 RM / 世界模型误差的手段不在 RM 本身，而在交互方式：关键帧/阶段入口重置（KIR）缩短想象深度；分阶段奖励和局部时域；PACE 用少量真实轨迹低频重训世界模型。
- RL 配置：G=8，每次更新 512 条想象轨迹，lr 5e-6，8×A100，与我们几乎相同。

### DRILL（arXiv 2610.30814）
- RM：冻结的视觉语言模型 rψ(o_t, ℓ) ∈ [0,1]，默认 Qwen3-VL-4B；换成 LLaVA-CoT-7B / InternVL-reward-4B 后结论不变（表 10）。
- 核心不在 RM：把世界模型的训练目标从像素 MSE 换成"下游策略回报"。DRILL-VWI 用策略访问分布、组内 GRPO 优势和模型置信度加权预测误差；DRILL-IMG 在真实仿真器里评估一步 GRPO 后的策略，用元梯度回传给世界模型。
- 关键结论：像素 MSE 更低不等于策略梯度更好；按"哪里影响策略决策"分配模型精度更有效。
- 局限：RM 冻结且未针对 RL 中的误判做处理；DRILL-IMG 需要仿真器提供外层回报。

### Do VLAs Know They Will Fail?（arXiv 2610.32208）
- 方法：OpenVLA-7B 在 LIBERO-10 上 500 条 rollout；第 0 层残差流（图像 token 平均）经 TopK SAE（2048 特征，K=64）；40 步滑动平均后用逻辑回归预测最终成败。
- 结果：全部帧 AUROC 0.80–0.81；在"不可挽回点"（PNR）之前 AUROC 0.71。PNR 用恢复仿真器状态、采样多条策略续写来估计：之后所有探测点的可恢复概率 ≤ 0.1 的最早时刻。
- 阈值权衡：τ=0.5 误报 64%、可干预 88%；τ=0.9 误报 14%、可干预 33%。
- 意义：失败信号可以从 VLA 内部特征里提前读出；用"仿真器分支估计可恢复性"来定义标签，比"回合是否失败"更有因果意义。

### 之前读过的（供对照）
- SafeDojo：RM = ResNet 256 px，从 WoVR RM 初始化，BCE + pos_weight；代价头 = Wan 潜变量 + 动作块 → 每步接触 logits；轨迹代价取最大的 16 个单步代价；budget 0.2，η lr 0.05；标签只有二值碰撞，作者自承不含接触力和接近距离。
- HaWMPO：不改 RM，用幻觉感知模块（冻结 DINOv3 + 融合 Transformer）给每条想象轨迹打可靠性分，再通过 Reward-Soft 软化奖励。

## 2. 共同点和空白

| 问题 | 已有做法 | 空白 |
|---|---|---|
| RM 误判 | 冻结 RM；靠缩短想象深度（WoVR/WoVR+）、软化奖励（HaWMPO）间接缓解 | 没有工作在 RL 过程中测量 RM 的在线精度，也没有量化 GRPO 能容忍多大的 RM 噪声 |
| RM 训练数据 | 演示 + 基础策略 rollout，首次成功后为正 | 没有用当前策略的 on-policy 难样本迭代重训 RM（WoVR 的 PACE 只重训世界模型） |
| 安全代价 | SafeDojo：二值碰撞标签 + top-16 聚合 | 没有工作检查代价标签是否漏报（我们发现 LIBERO robot 接触谓词恒为假）；没有"可恢复性"或接近程度的代价 |
| 模型训练目标 | DRILL：世界模型按下游回报训练 | 没有工作把同样的思路用到 RM / 代价模型 |

## 3. 我们已有、别人没有的东西
1. 同步的真实仿真器：每条想象轨迹都有真实成功、违规和三通道 grader 标签，可以在线测 RM / SAM 的精度（rm_online.json：精确率 .88–.95，召回率 .84–.89）。
2. 反事实分支数据（Step E 的 branch 轨迹）：可以像 PNR 那样估计"从这个状态继续是否还能安全完成"。
3. 修正后的接触 grader：三通道（obj / robot / grasp），带最小距离和法向力，可提供连续代价。
4. 系统的 oracle 拆分：E10-O（真实奖励）、E12-R（真实观测）、E7/E9（RM 奖励），能把差距分别归到观测、奖励、代价。

## 4. 候选创新点（需与上表的已有工作区分）

**A. 面向策略改进的 RM / SAM 训练（DRILL 思路迁移到奖励和代价）**
- 不按离线分类精度训练 RM，而按"对 GRPO 组内优势的影响"加权：组内能翻转优势符号的误判权重最大，组内全成功/全失败组里的误判影响小。
- 可以先做 DRILL-VWI 式的一阶近似：用同步仿真器给出的真实标签，计算每个样本的误判对组内优势的改变量，作为 RM 训练权重。
- 区别：DRILL 只训世界模型、RM 冻结；我们训的是 RM / 代价模型，而且有在线真实标签，不需要元梯度。

**B. 噪声容忍度 + 置信门控的 RM**
- 先做噪声注入实验，在真实奖励上加入和 RM 实测误差相同的随机翻转，确定 GRPO 能容忍的误报/漏报率。
- 再把 RM 改成"三值输出"：成功 / 失败 / 弃权；弃权的轨迹不进组内比较。阈值按噪声容忍度标定（类似 Do VLAs Know 的阈值权衡分析，但目标是 RL 稳定性而不是告警）。
- 区别：HaWMPO 是按世界模型可靠性软化奖励；我们按 RM 自身的校准置信度弃权，并有在线真实标签验证。

**C. 基于可恢复性的安全代价（借鉴 PNR，但用于约束 RL）**
- 用反事实分支估计每个状态的"安全可完成概率"，代价 = 该概率的下降量，而不是事后的二值碰撞。
- 好处：提前于违规发生给出梯度信号；对"成功前发生、但在第 64 步之后才显现"的 robot 违规更友好（第 0 步分析显示 robot 首次违规约一半在第 64 步之后）。
- 区别：SafeDojo 用二值碰撞 + top-M 聚合；Do VLAs Know 只做预测和解释，不用于训练。

**D. 代价标签审计（已完成，可作为分析贡献）**
- 发现并修复 LIBERO-Safety `check_robot_contact` 的 ID/名称不匹配：robot 接触谓词恒为假，训练代价从未包含 robot 违规；用统一 grader 让训练和评测共用实现，并有真实接触的集成测试。

## 5. 建议的验证顺序
1. 噪声注入实验（B 的前提，约 30 行代码 + 单测，10 步训练）：区分"随机噪声可容忍"和"系统性误判"。
2. 离线：用 E7/E9/E10 训练日志和同步仿真标签，检查 RM 误判集中在哪些任务、哪些行为（是否集中在抓错部位）。
3. 按结果在 A / B 中二选一实现，10–20 步短程对照，对比 E10-O（真实奖励）和 E8-a/E9（当前 RM）。
4. C 依赖反事实分支数据的覆盖情况，先离线评估可恢复性标签能否从 Wan 潜变量或 VLA 特征预测（AUROC），再决定是否上训练。

## 6. 表述边界
- 现阶段可以写：在真实监督下，Wan 观测足以支撑 GRPO 改进；E12-R 初步显示 affordance 上真实观测与 Wan 观测的 SR 接近（.570 vs .577，单种子、step 10、15 个 cell），但真实观测的 unsafe 更低（.203 vs .273）。robot 违规集中的 suite 结果还没出来。
- 不能写：Wan 可以替代物理引擎；无需仿真器。
